# SAE203 — Interactive Quiz Web Application

An interactive online Quiz application developed as an individual academic project for the **SAE203** module in higher education (IUT / University).

This full-stack web application allows users to browse, create, edit, and take custom quizzes on various topics with user authentication and score tracking.

---

## 🌟 Key Features

* **User Authentication & Profiles:** User sign-up, login/logout, and personal profile management with customizable avatars.
* **Quiz Catalog:** Browse available quizzes with filtering and selection options (`catalogue.php`).
* **Interactive Quiz Experience:** Take quizzes step-by-step with real-time feedback and dynamic scoring (`quiz.php`, `questions.php`).
* **Instant Results & History:** View detailed scores and feedback upon quiz completion (`resultat.php`).
* **Quiz Management & Creation:** In-app editor to create, update, and manage customized quizzes and questions (`edit.php`).
* **Administrative Utilities:** Pre-configured SQL initialization script for database setup.

---

## 🛠️ Tech Stack & Architecture

* **Back-End:** PHP 8+
* **Front-End:** HTML5, CSS3, Vanilla JavaScript (DOM manipulation, AJAX)
* **Database:** MySQL / MariaDB
* **Assets & Styling:** Custom CSS sheets (`quiz.css`, `profile.css`, `edit.css`) and vector/image resources.
